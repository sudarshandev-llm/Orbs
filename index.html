Orbs that look lit,
not drawn.

A small set of photoreal CSS orbs for AI assistants. Each one is built from a single key light, a bounce light and a fresnel rim — the three things that separate glass from a gradient circle. Drop one in, switch its state, ship it.

Usage

One file, one element. No framework, no build step, no network requests.

app.js 
// state is just an attribute
const orb = document.querySelector('assistant-orb');

orb.addEventListener('orbstatechange', (e) => {
  console.log(e.detail.previous, '→', e.detail.state);
});

// drive it from your assistant
orb.setState('thinking');
orb.setState('speaking');
CSS only (no JS) 
<!-- every /orbs/*.html file is self-contained, or use the stylesheet -->
<link rel="stylesheet" href="orb.css">

<div class="orb-stage" data-state="thinking"
     style="--orb-h:265;--orb-size:168px">
  <!-- markup from orbs/orb-3d-sphere.html -->
</div>
States retime everything idle breathes slowly, listening pulses, thinking spins the internal current up, and speaking pops the surface on an uneven rhythm because speech is not a sine wave.
Accessible out of the box The stage is a labelled role="img" that announces its state. Set decorative if the orb is pure garnish. All animation is disabled under prefers-reduced-motion.
Designed for dark surfaces These are lit objects: they need a dark room to glow in. On a light background, put them on a dark panel or reduce --orb-speed and accept a different look.

Zero build for consumers orb.js is a classic script, not a module, so it also works from file://. It has no imports and makes no requests — the CSS is inlined at build time.

One hue, whole material

The base colour is a single number. Shadows, bounce light, rim and bloom are all derived from it, so the light stays physically consistent.

theming 
<assistant-orb variant="sphere" hue="265" size="200"></assistant-orb>

What actually makes them read as real

No images, no canvas, no shaders. Just the cues your eye expects from a lit object.

One key light, everywhere Every gradient, shadow and highlight is anchored to a light at 33% / 24%. Break that and the orb instantly looks painted.
Fresnel, not a border The rim only appears at grazing angles. It is a screen-blended radial ring, never a stroked edge.
Bounce and contact A cool bounce lights the lower right of the sphere, and a separate soft shadow stays on the floor while the orb floats above it.
Grain that moves Static noise reads as a texture; noise that re-rolls 24 times a second reads as film. Two layers at different speeds kill the tiling.
Depth rigs The gyro is drawn twice — a dimmed, blurred rig behind the core and a sharp one in front — so rings genuinely pass behind it.
Real 3D, not fake ellipses Meridians are circles rotated on the Y axis inside a preserve-3d rig. The projection is done by the browser, so it is always correct.
